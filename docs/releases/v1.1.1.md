# My Game Launcher v1.1.1

This maintenance release fixes Windows game-process tracking for elevated games and launcher/anti-cheat handoffs.

## Fixes

- Fixed games that launch successfully through a UAC administrator prompt but were later reported as:
  `The game was launched, but its running process could not be detected within 60 seconds.`
- Removed the requirement to read privileged `MainModule.FileName` data before accepting an elevated game process.
- Added Windows Toolhelp process snapshots for UAC-safe PID, executable-name, and parent/child process tracking.
- Added generic launcher / bootstrapper / anti-cheat → real game process handoff detection.
- Prevented the launcher from attaching to pre-existing same-name processes.
- Prevented common storefront and anti-cheat helper processes from being mistaken for the game.
- Changed game-lifetime tracking to PID/process snapshots so playtime tracking does not depend on privileged process handles.
- Preserved the final detected game PID for overlay/FPS tracking.

- Windows Release build: **0 warnings, 0 errors**
- Launcher test suite: **58/58 passed**
- Includes regression coverage for elevated/inaccessible process paths, process-tree handoffs, helper filtering, and Windows process enumeration.
