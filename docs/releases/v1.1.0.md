# My Game Launcher v1.1.0

This release focuses on polish, telemetry reliability, personal-library integration, and maintainability.

## Highlights

- Added a proper Windows launcher, executable, and installer icon.
- Reworked the dark UI for readable headers, controls, selection states, and improved game cards.
- Fixed RTSS overlay duplication for GPU telemetry.
- Improved FPS detection when a game renders from a child/foreground process.
- Replaced the Hatchable launcher integration with **Personal Game Library** backed by Google Sheets.
- Added persistent local **1–10 game ratings** with safe SQLite migration.
- Updated Next Play, controller mode, stats, and syncing around Personal Game Library.
- Removed obsolete Hatchable production code.
- Refactored startup composition, personal-library matching/parsing, and repeated view-model construction.
- Split the monolithic test runner into domain-focused test files.
- Centralized repository code-style and build conventions.
